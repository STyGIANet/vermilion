All-to-all traffic weights in this codebase come from the weight matrix file that main_tcp_mixnet (and other mains) pass into FFApplication::load_taskgraph_flatbuf via -weightmatrix (default ../../../test/num_global_tokens_per_expert.txt). load_weight_matrix parses the first line into an 8x8 int matrix and checks each row sums to 32768. When building an all-to-all task (src/clos/ffapp.cpp:360-436), total_xfer_size is xfersize * ep_degree; for each (from,to) expert pair the per-flow size is scaled by the weight entry: GROUP_BY forward or AGGREGATE backward uses weight_matrix[src_exp][dst_exp]/32768, the opposite direction uses weight_matrix[dst_exp][src_exp]/32768. The result is ceil’ed and stored in operator_sizes[fn,tn], which drives actual flow sizes; other comm types use the unscaled xfersize from the task graph. Thus the weight matrix entries set the fraction of total_xfer_size each expert pair exchanges.

Because the weight lookup is directional, the same src/dst node pair can get two different flow sizes in different all-to-all directions: GROUP_BY forward/AGGREGATE backward scales with weight_matrix[src_exp][dst_exp], while the opposite direction scales with weight_matrix[dst_exp][src_exp].
